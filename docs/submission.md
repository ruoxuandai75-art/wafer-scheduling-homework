# 作业提交说明

## 第一周

模板路径相对于项目根目录。推荐复制 `docs/notes/W01_作业模板.docx` 为 `docs/notes/W01_我的作业.docx`，用 Word 或 WPS 填写；也可复制 `docs/notes/W01_作业模板.md` 为 `docs/notes/W01_我的作业.md`，两种格式只需提交一种。附件放在 `docs/notes/W01_附件/`。按 [Windows 学习指南](week01_windows.md) 完成 AI 基础、环境与编辑器证据、三道场景题和 commit／push。

在课程提交入口填写：个人仓库链接、实际分支、包含本次答案的完整提交编号、记录相对路径。编号在提交完成后获取，不需要写回被该提交包含的记录文件。按学习材料创建公开（Public）个人仓库，并确认师兄可以访问。

账号、访问权限、网络或认证受阻时，如实列出未完成项，可先交本地记录用于反馈；这些替代材料不代表 clone 和 push 已完成，后续仍需补验。

Word 文档提交前先保存并关闭，在 Word 或 WPS 中检查正文，再用 Git 核对文件名并提交。推送后核对 GitHub 上的仓库、分支、文件与提交编号；无法在线预览 .docx 时，下载本次提交中的文件打开核对答案。推送结果与最终编号在提交入口提供，不再写回当前作业。

## 后续主题

按对应任务清单提交。若当周允许，可选择记录文档与项目压缩包，或个人仓库链接、分支和完整提交编号。保留实际运行命令、Python 版本、结果与手算核对；附件采用相对路径。

提交前在自己的项目中检查引用的文件齐全，仓库不包含环境安装目录、缓存、密码或访问令牌。
